使用方式

1. 在「上游平台」填入每个 AI 平台的 Base URL 和 API Key，系统会自动拉取模型列表。

2. 在「下游密钥」生成一个 sk-selfapi-xxx 密钥，供你的客户端使用。

3. 客户端以 OpenAI 格式 调用下方 endpoint，同名模型会自动在多个上游间轮换，单平台失败立即切换。
